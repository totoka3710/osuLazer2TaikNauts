# osuLazer2TaikoNauts

osu!lazer が管理するハッシュ化されたストレージから **osu!taiko 譜面** を抽出し、太鼓シミュレーター [TaikøNauts](https://taikonauts-docs.pages.dev/) へシンボリックリンク形式で同期・提供する Windows 向けユーティリティです。

実体データをコピーせずシンボリックリンクで参照するため、**ディスク容量を追加で消費しません**。
また、キャッシュ管理ファイル（`manifest.json`）による高速な差分検知を行うため、ストレージへのアクセス負荷を最小限に抑えつつ、2回目以降の同期を一瞬で完了します。

---

## 🚀 主な機能・共通仕様

- **容量ゼロのシンボリックリンク同期**
  - osu!lazer 内の原本（ハッシュファイル）を指すシンボリックリンクを生成し、ストレージ容量を消費しません。
- **taiko 譜面専用フィルタリング**
  - スタンダードや mania などの他モードの `.osu` ファイルを除外し、純粋な太鼓譜面とその関連アセット（音源・画像・動画）のみを抽出。
- **キャッシュ（`manifest.json`）による超高速差分更新**
  - メモリ上で前回同期時のハッシュ一覧と最新の Realm データを比較。
  - 新規追加・更新・削除（osu!側で消えた譜面の自動クリーンアップ）の差分のみをディスク操作します。
- **安心・安全設計（完全読み取り専用）**
  - osu!lazer の原本ファイル群や `client.realm` には一切の書き込みを行いません。
  - 同期先で削除対象となるのは、ツールが管理する `osuTaiko` 内のシンボリックリンクおよび空フォルダーのみです。
- **GUI / CLI ハイブリッド動作**
  - エクスプローラーからダブルクリックで起動すると視覚的な GUI ウィンドウが表示されます。
  - コマンドラインやバッチファイルから呼び出された場合は、自動で CLI モードとして動作します。
- **設定の永続化（`config.json`）**
  - 実行ファイルと同じ階層にパス設定が自動保存され、次回以降の実行時は引数なしで自動実行可能です。

## 📂 生成されるディレクトリ構造

TaikøNauts の `Songs` フォルダーを指定すると、その直下に `osuTaiko` フォルダーが作成されます。

```text
Songs/
 └── osuTaiko/
      ├── manifest.json                     # 同期管理キャッシュ
      ├── error.log                         # エラー発生時のみ出力
      ├── <曲名>_<アーティスト>_<UUID>/
      │    ├── xxx [Oni].osu                # 譜面ファイル (シンボリックリンク)
      │    ├── audio.mp3                    # 音源ファイル (シンボリックリンク)
      │    └── bg.jpg                       # 背景画像等   (シンボリックリンク)
      └── ...
```

> **Note**: 同期完了後、TaikøNauts の選曲画面で **F2 キー** を押すと曲リストが即座に再読み込みされます。

## 🤖 3つのエディションと各README

本プロジェクトでは、同一の設計思想（共通の `manifest.json` 仕様）のもとで、3つの AI（Antigravity / Claude / Codex）によって実装されたエディションを提供しています。内部処理のアプローチや細かな機能に違いがありますので、用途や好みに合わせて選択してください。

各エディションの詳細なオプション仕様やビルド手順は、それぞれの README を参照してください。  

| エディション | 特徴・推奨用途 | 詳細ドキュメント |
| :--- | :--- | :--- |
| **Antigravity Edition** | **洗練されたGUI & ダークモード完備**<br>Windowsテーマ自動連動のダークモード、直感的なファイル選択ダイアログを搭載。完全単一EXE構成。 | [👉 Antigravity 版 README](Antigravity\README.md) |
| **Claude Edition** | **CLI機能の充実 & 高度な安全性チェック**<br>実行前の `--dry-run`（テスト実行）、Windows予約名（CON/NUL等）の例外処理、詳細なエラー検知を実装。 | [👉 Claude 版 README](Claude\README.md) |
| **Codex Edition** | **Realm スキーマ自動検出 & 堅牢な .NET 10 最適化**<br>Realm Studio との互換性、スキーマバージョンの動的追従に優れ、最もミニマルで堅牢な設計。 | [👉 Codex 版 README](Codex\README.md) |

### `manifest.json` の互換性について
すべて共通の JSON スキーマ（`last_synced`, `beatmap_sets`, `folder_name`, `files`）で設計されています。そのため、**あるエディションで初回同期を行った後、次回以降に別のエディションを実行しても無駄な再生成は発生せず、差分更新が正常に引き継がれます**。

## 💻 動作要件・前提設定

- **OS**: Windows 10 (バージョン 1703 以降) / Windows 11 (64bit)
- **Windows 開発者モード（強く推奨）**:
  - Windows の **[設定] > [プライバシーとセキュリティ] (または [更新とセキュリティ]) > [開発者向け]** で **「開発者モード」をオン** にしてください。
  - 開発者モードを有効にすることで、シンボリックリンク作成時の管理者権限（UACダイアログ）昇格なしで実行できるようになります。
- **ビルド環境（ソースからビルドする場合のみ）**:
  - [.NET 10 SDK](https://dotnet.microsoft.com/download) または [.NET 8 SDK](https://dotnet.microsoft.com/download)

## ⚡ クイックスタート (ビルド & 実行)

リリースページからお好みのエディションをダウンロードしてお使いください。  
もしくは、各エディションのフォルダー内で以下のコマンドを実行することで、単一の自己完結型 EXE を出力できます。

```powershell
# 例: Antigravity 版をビルドする場合
cd Antigravity
dotnet publish -c Release

# 生成された EXE を起動（初回のみ Songs パスを指定）
.\bin\Release\net10.0-windows\win-x64\publish\osuLazer2TaikoNauts.exe --output_path "D:\TaikoNauts\Songs"
```

2回目以降は、エクスプローラーから `osuLazer2TaikoNauts.exe` をダブルクリックするか、バッチファイルから引数なしで実行するだけで自動差分同期が行われます。

## ❓ トラブルシューティング

- **「シンボリックリンクを作成できない」というエラーが出る**:
  - Windows の「開発者モード」を有効にするか、実行ファイルを右クリックして「管理者として実行」してください。
- **osu!lazer のデータベースが開けない**:
  - osu!lazer 起動中に実行すると DB がロックされている場合があります。一度 osu!lazer を終了してから同期を行ってください。
- **TaikøNauts に反映されない**:
  - TaikøNautsのsongPathを確認してください。詳しくはTaikøNauts公式ヘルプを参照してください。
